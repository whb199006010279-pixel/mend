mend is one command-line tool that applies the edits AI models write, in four formats — unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON tool calls — to a tree of files. If any edit fails, nothing is written.

## Run it

```sh
node main.ts [options] [PATCH]
```
